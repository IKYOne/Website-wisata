Tentang Website Ini

Website ini dikembangkan sebagai platform latihan mandiri untuk membangun aplikasi web profesional dari nol menggunakan bahasa pemrograman Golang tanpa bantuan *framework* berat eksternal.

Teknologi & Skill yang Digunakan

Golang (net/http)

Menggunakan fitur routing modern Go 1.22+ dan manajemen server mandiri.

HTML5 & CSS3

Desain antarmuka responsif menggunakan Flexbox dan sistem *Grid* murni.

In-Memory State

Pengelolaan data autentikasi login dan register berbasis *slice* dan *struct*.
